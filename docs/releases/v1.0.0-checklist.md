# v1.0.0 release checklist

This checklist is completed only from fresh feature/merge/deployment evidence. It is intentionally checked in before release so the final release record has one concise gate list.

- [ ] `main` clean
- [ ] `main` synchronized with `origin/main`
- [ ] all Python and web tests/gates green
- [ ] feature CI green
- [ ] merge CI green
- [ ] production migration current
- [ ] scheduled production pipeline green
- [ ] public UI healthy at desktop and mobile sizes
- [ ] public APIs healthy and bounded
- [ ] secret scan pass
- [ ] npm audit pass
- [ ] Python dependency compatibility/security result recorded
- [ ] Cloudflare runtime dependencies zero
- [ ] public mutation handlers zero
- [ ] public inference handlers zero
- [ ] README current
- [ ] architecture and data-flow diagrams current
- [ ] screenshots current and secret-free
- [ ] release evidence complete
- [ ] limitations documented
